# Arcane: The Free Docker Dashboard Every Home Server Needs

Video: https://youtu.be/1ITJ3Q2jNXI (2026-10-05)
Written guide, with every command explained: https://sethcomire.com/arcane-docker-dashboard/

Installs Arcane, a web dashboard for managing your Docker containers and Compose projects. Needs [Docker + Docker Compose](../docker-compose-ubuntu/) first.

- [compose.yml](compose.yml): the compose file, for `/opt/docker/arcane`
- [.env.example](.env.example): what the `.env` file looks like (make your own key, see the comment inside)

Official docs: https://getarcane.app/docs/setup/installation
